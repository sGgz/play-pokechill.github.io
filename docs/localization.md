# 简体中文与手机界面

本分支保留原游戏风格，菜单、新手引导、设置、图鉴、道具、战斗、研究和提示使用简体中文。手机宽度不超过 1000px 时，运行中的云存档入口移入“菜单 → 云存档”，收起面板后不覆盖游玩按钮。启动检查和冲突处理仍直接显示面板；桌面保留右上角入口。

## 译名来源

2026-10-10 联网同步 PokeAPI 的 `zh-hans` 游戏译名，共 4808 条名称记录，固定数据提交为 `c80757193bd0889054e36f4209762360bdaa4b95`。数据包括宝可梦种类与形态、道具、招式、特性、属性、性格和地区。它是社区收集的游戏本地化数据，**不是宝可梦公司的官方服务，也不能把整个词库宣称为已逐条官方核验**。

抽查官网图鉴中的 [草苗龟](https://pokedex.pokemon.cn/play/pokedex/0387)、[火斑喵](https://pokedex.pokemon.cn/play/pokedex/0725)、[呱呱泡蛙](https://pokedex.pokemon.cn/play/pokedex/0656) 和 [皮卡丘](https://pokedex.pokemon.cn/play/pokedex/0025)，核对名称、属性及特性；新增超级雷丘与进化石名称可参照 [官方 Z-A 页面](https://www.pokemon.co.jp/ex/legends_z-a_dlc/sc/pokemon/250912_01/)。来源地址、数据版本与 SHA-256 在 `scripts/i18n/name-sources.json` 留档。名称从源数据读取，不对官方英文专名逐词机器翻译。

`scripts/i18n/custom.mjs` 单独存放 PokeChill 原创特性、道具、招式和区域的中文名称，这些内容没有对应的官方译名。`reviewed.mjs` 和 `ui.mjs` 是本项目界面、规则和补充显示词条；补充的旧世代饰品、地点、训练家名称并非全部经过官网逐条核验。鲤鱼王跳跃的六种特殊花纹暂保留英文花纹标签，避免杜撰“官方译名”。如有可核验的新来源，应在来源说明中补充后再修改。

## 兼容性

中文仅改变显示层。宝可梦、招式、道具、区域 ID，原版存档结构、图片路径和云存档协议保持兼容。原代码拼错的 `airShlash` 等 ID 通过显示别名关联“空气斩”，不重写旧进度。

宝可梦和道具名称支持中英文搜索；属性、特性、招式搜索接入中文显示名，搜索关键词如“异色”“已捕获”“水属性”会转换为原查询语法。玩家输入的昵称、队伍名和标签不参与翻译，输入框值、代码示例、链接和数据属性不参与自动改写。

界面翻译不需要联网：构建时将词库与 DOM 翻译逻辑打包进 `dist/scripts/zh-cn.js`，动态加入的提示会自动使用中文。官方图鉴来源不会在游玩时发送查询。

## 更新与部署

在项目根目录使用 Node.js 24：

```cmd
npm run i18n:sync
npm run verify
npm run cloud:deploy
```

同步工具联网下载 CSV，固定并记录实际数据提交。只更新译名无需重新创建云槽位、设置密码或重建存档仓库。保留已有的本机 `wrangler.local.json`，其中真实域名、槽位 ID 均不提交到公共源码仓库。部署后刷新手机页面加载新构建。

`test/localization.test.mjs` 检查名称覆盖、官方名称样例、内部 ID 与学习器图片路径兼容、动态界面翻译和用户输入保护；菜单开关沿用真实云控制器回归测试。浏览器验收使用本机假存档服务，不接触玩家的真实云档。
